# PostRiff founder-alpha onboarding copy

Date: 2026-09-14. Customer-facing copy in the local alpha; provisional founder input, not findings from five interviews. Phase 0 remains incomplete.

## Sequence and boundaries

Five visible chapters: Your agency → Your AI → Your profile → First PostRiff → Review and save. The research interview is not customer onboarding. Each question is presented separately; confirmation saves its answer and Back returns to prior state. Unconfirmed editor text is kept in this browser. Optional answers may remain unknown. Hybrid requires its building blocks and speaker.

## Welcome and account

Welcome: “Build your social media agency around your voice.” Set up my agency; Explore with a sample. The sample is read-only and memory-only.

Account: “Save your agency and use it anywhere”. In this alpha the visible simulated-account explanation immediately qualifies that future-facing title: local adapter only; no OAuth/email/SMS/cloud/trial. Google, Apple, Microsoft, email, phone and existing-account choices are available. Example email/phone and the displayed code 123456 are fixtures. Failed verification focuses “The preview verification did not pass. Use the displayed fixture code; nothing was sent.”

## Transfer and scope

Choices: use a CLI on this computer; copy a prompt into my AI; use both and compare; continue with PostRiff questions. Scope asks what the AI may use, with current conversation, saved memory if accessible, specifically selected projects/files/examples and questions as separate choices. The user must explicitly confirm scope. Unselected histories/files are never accessed. Retention is references only unless a writing excerpt is separately approved.

Handoff: “Bring useful context. Keep the final say.” “Prepared · not executed.” Download/copy the complete builder prompt or scope manifest. CLI controls inspect only executable versions and display a blocked unqualified job. Import only a selected candidate, never credentials or a raw conversation archive.

## Field-level review

“Does this feel like a useful starting point?” Each field displays its exact value, evidence, confidence, source references and privacy. Actions: Approve, Edit, Reject, Keep unknown. Privacy: May inform public drafts; Workspace context only; Private interaction guidance; Keep on this device; Exclude this value.

“Approve my stated answers” covers only low-risk directly supplied answers. Agent proposals, conflicts and optional self-descriptions require individual decisions. “Use this reviewed profile” stays unavailable while any field is pending. The profile is provisional, editable, and grants no tool or publication authority.

## First idea, source and runtime

“What would you like to create first?” Write an idea; paste a link or text; add a document I can use; try a sample topic. Sources create fact proposals. “Confirm selected facts” approves selected statements for use, not independent truth. “Withdraw this source” excludes it from later retrieval and invalidates affected exports.

Documents: UTF-8 .txt/.md, up to 20 KB. Other types are rejected with a focused explanation. A pasted URL is recorded but not fetched. Business requires at least one approved fact; a personal idea can remain an outline.

Writing setup explicitly offers the local deterministic preview. Real agent routes are untested/unqualified; managed writing is blocked. No provider fallback runs automatically.

## Draft calibration and return

“One idea. A few good riffs.” “Deterministic preview · no model called.” Each platform/language draft is editable and has an opening plus two alternatives. “Which opening feels most like you?” includes “None of these — I’ll edit my own”.

After an edit: “Remember this”, “Only for this post”, or “Don’t use this”. Undo and deletion remain available. Changes to a shared brief/profile preserve existing text and show a proposed replacement before acceptance.

“Your first PostRiff is ready.” Save in Ideas; export drafts; continue editing. “Welcome back to your agency” restores confirmed answers, current idea, independent variants and approved preferences. The export is local and private; it is not a publication.

## Error and recovery copy

- Changed workspace: reload the saved version; unsent text stays in the local editor.
- Changed source/brief/profile: review replacement drafts before saving/exporting.
- Simulated failure/quota: source, profile and existing drafts are safe; retry the local preview or keep editing.
- Missing/unsupported CLI: version/auth/access/execution states remain distinct; use the portable prompt or guided questions.
- Invalid package: supported schema, paths, UTF-8, hashes and links are required; commands/hooks are never executed.

The eight-minute activation target and voice-recognition goals remain human-test hypotheses. Timestamps exist for profile start/review, source approvals, runs and saving; automated speed is not customer evidence.
