# Rafii V3 Stage 3 — Radar

Local implementation from Phase 2 `38a3a06`, in an isolated worktree. Governing V3 artifact: https://claude.ai/artifact/Rh24Gowc3Ni3xnVX9cGXcq (read 2026-09-27, sections 11–18 and 20). The original V2 document was superseded in that artifact; this implementation follows its retained V3 requirements.

Deliver Quick/Deep scans, Genome-aware For You, inspectable evidence and source diversity, bounded verification, existing Ideas handoff, Home entry and default-off lightweight monitoring. Reuse growth judgments, model routing, usage ledger, owner permissions and the existing credit wallet. Native YouTube metrics remain unranked; search results remain leads. No automatic content publication. Scan batches commit progress before external attempts; unknown attempts are not replayed. Feature flag: POSTRIFF_RADAR, with POSTRIFF_GROWTH.

Source adapters use official public endpoints or explicitly configured API access. Exa is already part of the project's research architecture; marketplace discovery confirmed Exa, so no new account/service is installed. Missing API keys, permission or approved pricing is an unavailable capability, not fabricated data. RSS, Mastodon, Threads/Instagram public discovery, and Google Trends remain unavailable until provider-specific permission/configuration is supplied.

Quick/Deep prices in the design are candidate policies. Do not activate new plan terms. Use existing active wallet terms where present; otherwise use a configured growth allowance. Real provider execution, credit-policy activation, platform applications, production migration, external alerts, push and deployment require separate release scope. Tests use deterministic adapters and disposable data only.

Release efficacy remains separate: real Precision@5 >= .6, >=30% weekly users creating a draft, and complete actual cost <= quoted ceiling. No synthetic fixture establishes any of these.
