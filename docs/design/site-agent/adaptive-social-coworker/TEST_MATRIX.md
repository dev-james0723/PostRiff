## Not covered locally (needs live accounts or a production-like build)

- A real Resend send, and a real webhook from Resend.
- A real push to a device through FCM, Apple or Mozilla.
- A live writer model phrasing weekly drafts. The preview writer is deterministic.
- Live image generation or editing.
- A live GPT-Live voice session.
- The production build on Vercel.
- Load at production scale.

The handoff lists each one with its account, cost and rollback. `scripts/rafii_coworker_verify.py` reports an evidence-file gate as STALE (and exits non-zero) when any file it covers changed after the evidence was written.
