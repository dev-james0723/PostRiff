## Behaviour to deliver (all of it)
1. Dialog `ChannelBloomDialog({ open, onOpenChange, accounts, folders, selected, context, onCommit })`: `accounts: FolderAccount[]` built from `state.phase2.channels` (id, platform, account, displayState → connected = !revoked). Draftable = platform in `DRAFT_PLATFORMS`; others render disabled with the reason "Drafting is not available for {platform} yet". Header: eyebrow "Channel Bloom", title "Where should it <em>go?</em>", intro, close (Cancel). Search field matches folders and accounts (`folderMatches`/`accountMatches`). "Your folders · N" + New folder. Shelf: 2-column glass folder cards (`SegmentedControl` is not for this; build the card per `folders-v9.css`): main hit area = `role='checkbox'` with `aria-checked` true/false/'mixed' toggling the group (`toggleGroup`), separate chevron button `aria-expanded` opening the inspector directly beneath that card's row (span both columns after the row containing the card); state text "3 accounts" / "2 of 3 selected" / "3 selected"; missing members shown as "1 no longer connected". Pinned mark. At most 4 on the compact shelf, "View all N folders" / "Show fewer". Empty state when no folders ("Keep your usual accounts together." + Create your first folder).
2. Inspector: heading, Edit, More (menu: Pin/Unpin, Duplicate, Move up, Move down, Delete → inline confirmation "Delete “X”? This removes the folder only. Accounts and draft destinations stay unchanged."). Member rows are checkboxes editing the same staged selection; note "Changes here are just for this draft. The saved folder stays the same." Use `useMeasuredDisclosure`/`animateHeight` for the unfold (480ms) and small stagger on the platform marks; reduced motion → instant.
3. Individual accounts section: every account as a row (platform icon via `ChannelIcon`, platform label, handle, state such as "Ready for posting"/"Finish setup"/"Reconnect"), checkbox synced with the staged set.
4. Footer: feedback line with Undo (restores previous selection AND its folder context), Clear, Save selection as folder, primary "Done · N accounts selected", storage note "Folders are saved to this workspace" (not localStorage). Done → `onCommit({ accountIds, context: snapshotContext(folders, originIds, accounts) })`. Cancel/close/Escape discards staged destination changes but never undoes a saved folder edit.
5. Editor view (New folder / Save selection as folder / Edit): back button, live folder object + name preview, name field (48px, 16px text, counter "n / 40"), symbols (6, `aria-pressed`), "Pin to the folder shelf", member checkboxes (all accounts; disconnected members of an existing folder shown as such), inline error text from `validateFolder`, note "Saving changes the folder only. Your current draft destinations and output settings stay untouched.", Cancel + "Save folder" (disabled until valid). Save → `p2_folder_save` with expectedRevision (409 → refetch snapshot, retry once; other errors shown inline, nothing lost). Delete → `p2_folder_delete`; pin/duplicate/move → save/move actions. After save, focus returns to that folder's chevron; after cancel, to the previous trigger.
6. Keyboard: Tab order sensible inside the dialog (Base UI dialog traps focus), Escape closes the deepest layer first (menu → delete confirm → editor → inspector → dialog), Enter in the name field saves when valid. Screen reader: `aria-live` status for feedback.
7. `use-destinations.ts`: `{ selected: string[] (channel ids), platformOnly: string[] (platforms drafted without an account), context, commit(sel), clear(), summary: selectionLabel(...) }` persisted for the session per workspace (sessionStorage key `rafii.destinations.<workspaceId>`), never in the URL. Migration of the prototype's localStorage folders: NOT implemented (no such data in this product); do not auto-import demo folders.
8. Tests: `web/src/features/channels/channel-bloom/channel-bloom.test.cjs` for any pure helpers you add (e.g. inspector placement index, missing-member text); keep `folders.test.cjs` green. `npm --prefix web run typecheck` and `lint` must pass.
