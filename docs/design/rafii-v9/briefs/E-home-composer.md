## Wiring
- Destinations: `useDestinations` (accounts) + `useChannelLanguages` per selection item; `api.quickStart` gets `destinations: Destination[]` with `channelId`.
- Content type: `content-choice.ts` selection applied on generate (as today) and shown in the pod; planning-only note under the pod.
- Voice dialog: Neutral vs Personalized (eligible samples via `eligibleVoiceSources`), link to Brand page; no fake tones.
- Model/reasoning: `useModelChoice` + per-model reasoning; send `choice.reasoning` mapped by the route.
- Conversation view: same Composer (compact), same dialogs, VariantCard shows `account` + `channelId`, DraftPreview uses `channels.find(c => c.id === variant.channelId) ?? by platform`; PlanCard rows default `channelId` from the variant.
