# Control → service wiring matrix (v9 homepage, selectors and conversation)

Columns: v9 control | production component | real read/write/job action | state owner | persistence | error/cancel behaviour | verification.

Verification legend: **PW** = Playwright real-input run against the local dev harness (`web/tests/rafii-workflow.cjs`, report in `evidence/workflow/<browser>/report.json`, Chromium and WebKit); **node** = `node --test` unit/contract test; **py** = Python unit test; **pg** = disposable-PostgreSQL integration script. All drafting in automation uses the `deterministic-preview` fixture route (the script aborts any other model before it reaches the server); nothing is published.
