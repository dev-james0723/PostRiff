## 4. Writes, queries, authority
- D-A12 Native OpenUI `Mutation` is forbidden (0.3.2 cannot intercept it). Writes only via Rafii `ActionButton`/`Form` → bridge (React context outside the generated subtree) → native confirmation (server copy from `/actions/activate`) → `POST /actions` with `activationId` + `idempotencyKey`. - D-A13 Host `onAction` handles only `continue_conversation` (prefill/send a labeled follow-up via the existing turn path with `uiContext`; drop `params.context`; never forward raw `formState`) and `open_url` (same-origin allowlist). All other types ignored. Generic buttons forward only sanitized plans (`set`,`reset`,`continue_conversation`,`open_url`,`run` of a query).
- D-A14 UI action authority = static allowlist in `ui_actions.py` (actionId → original domain command, permission class, step-up, effect class ∈ `UI_ACTION_EFFECTS`). Never `permissions.classify()` on generated names. Prepared ≠ applied in every native label.
- D-A15 Durable idempotency + activations: tables `pr_ui_actions` / `pr_ui_activations` (migration 102). Write the receipt in the same transaction as the domain command. Same key+digest → stored result; same key/different digest → 409 `conflict`. `input_digest = ui_contracts.input_digest(actionId, inputs)` computed server-side only.
- D-A16 Queries: one `ui_transaction` per request, call existing pure readers directly (site_agent tools/reads, UniversalLibrary, learning readers, insights.summary/performance), never HTTP self-calls or the Manager tool registry. Rate admission via existing `hosted.throttle(cur, 'ui-query:<principal>:<artifact>', 60, 60)`. Results are `ui_contracts.query_result` (unknown ≠ zero; coverage + asOf; `unavailable` names the real reason). Metrics computed server-side (OpenUI builtins zero-coerce unknowns).
- D-A17 Presenter sees only binding schemas, counts, kinds, states, rule labels and opaque refs. Never private text (drafts, voice samples, memory bodies, extracted Library text, evidence quotes), media bytes, signed URLs, `createdBy`, provenance. Values reach the browser only through bound queries.
