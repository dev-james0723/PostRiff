## 3. Rules for closing a row

A row moves to CLOSED only when (a) the fix commit is an ancestor of the final SHA, (b) the named tests pass on the final SHA, (c) at least one named test fails on the commit before the fix (shown by running it), and (d) the review of the final SHA says so in its own words. No row is closed by this document alone.
