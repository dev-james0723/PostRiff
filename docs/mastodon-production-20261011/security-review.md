Validated address pinning preserves TLS hostname checks. Default requests have one absolute 20-second DNS/socket/header/body deadline; DNS uses bounded four-thread/eight-reservation admission, holding a running resolver reservation until it actually ends. - OAuth issuer/origin, redirect, instance/account and conditional S 256 PKCE binding; effective scopes cannot expand beyond the token grant. One-time callback claim commits before exchange. Vault-encrypted per-instance app cache and tokens, database advisory serialization; no secrets in browser storage and no assumed refresh support.
- Exact action previews bind workspace, current actor, instance-qualified account, target, content/scopes/digest and ten-minute expiry. Membership and exact unrevoked credential are rechecked before execution. Durable claim commits before effects; duplicate approvals and ambiguous effects never resend. Read admission precedes remote OAuth verification; an exhausted SQL quota regression proves zero provider calls.

Disposable PostgreSQL verifies browser-role denial, tenant isolation, credential/revocation fences, native amendment preserving approval and leases, retention and reconnection races. These migrations are not applied to production.
- Frozen private media size/hash/object/custody is checked before approval and worker dispatch. Accepted media IDs and every external intent are checkpointed. Known media resumes by ID; unknown writes never retry. Queue permits only rights-confirmed described images or a verified normalized audio/video asset. Fresh server limits are checked before publication.
- Thread children use exact saved parents and per-part idempotency keys; current identity/content/settings and each saved post are checked before whole-thread verification. Single-post/native language/reply/poll options/quote/sensitivity use the same matcher. Semantic mentions and observable poll expiry remain follow-ups. Native pending remains processing; missing text-only schedules do not prove publication. Media-native read-back needs a unique matching owned post. Transient grant checks retain known IDs and bounded cooldowns; ambiguous external intent never becomes a retryable unsent operation.
- Fenced shared worker completion now isolates optional SQL insights hooks with a savepoint. A real failed SQL callback cannot poison the conclusive publication receipt; completion repeats do not run the callback twice. Lease/credential/approval fences remain required.
- Private/followers-only/direct bodies stay outside broad Analytics and Agent model tools by default. Native metrics include only bounded public/unlisted numeric counts, exact current credential/instance and real observed UTC readings; no invented impressions/reach/demographics. Foreground SSE is bounded and ephemeral, with current authorization rechecks before private excerpts return. Private reply/mention AI requires purpose consent and retention work before release.
- OAuth management is not automation consent. Existing owner grant/default approval/pause fencing must receive Mastodon-specific SQL/worker and real acceptance evidence. Agent tools prepare unapproved reviews only, preserve current human request gating and do not acknowledge warnings or execute publication.
