# Creative Intelligence in Rafii

## Product contract for the first wave

An editor starts with a video the workspace may analyze, a short campaign brief, a destination and an output orientation. Video Studio measures the reference locally, proposes an editable original shot plan and shows the workspace brand context behind it. A workspace approver can request and fund one new take for a scene. An editor can also assign footage the workspace already owns. The editor can save a revision, render a private MP4, return to an earlier export and change one shot without replacing the others.

The reference has permission for analysis. Output footage needs its own permission. Keeping the input in the same Library does not confer permission to use its pictures, sound, words, music or likeness. A second copy with the same bytes is also rejected at render. Re-encoding a third-party work changes its digest, so the attestation and editorial rights review still matter.

## Interface and lifecycle

The route prefix is `/api/workspaces/{workspace}/creative-video/projects`. A session can list projects, create one using a retry-safe request ID, and read the current project or `?revision=N`. An editor posts a saved revision to `/{id}/edit` or `/{id}/render`. An approver uses `/{id}/generate` and `/{id}/poll` with a scene ID. Historical content is read-only. The UI lists the latest 100 projects. Each known project has an address and a revision history.

The analysis and rendering functions receive private bytes. Decoder inputs use inherited file descriptors, bounded probes and fixed media filters. The visual timeline admits up to 90 seconds and 32 editorial scenes. Each input is bounded at 64 MiB, and unique composition input is bounded at 128 MiB. Rendering uses H.264, AAC, selectable timed text and 24 fps. The web project offers 9:16 and 16:9. Playback before export can inspect individual source clips. Composition preview plays the saved export.

At intake, optional offline English OCR reads up to three representative frames. It returns actual sample times, word counts, confidence and coarse overlay geometry. Punctuation and a small English invitation vocabulary can suggest an opening question or closing call to action. The project retains the structural clues and discards the recognized wording. These measurements are absent in older saved projects; those projects remain readable. The analyzer excludes this extra OCR pass when validating a provider's output.

Provider submission and media processing take place outside the locked SQL transaction. The worker rechecks current state before attaching a result. A definitive rejection, lost acknowledgement, expired operation, unusable output or later authorisation change each has a distinct reconciliation disposition. An uncertain reservation stays visible until the canonical billing owner has evidence. The adapter never switches to another model or service on error. An account grant, cost estimate or provider receipt alone does not prove acceptable footage.

## Brand, creative and performance learning

Approved brand facts, voice and confirmed preferences are inputs to the first blueprint. A creative direction or caption the editor types belongs to that revision. Existing Brand Brain controls own confirmation, retirement, reset and future memory use. Generation binds exact grants and current memory. Reopen a new project with fresh context when the pinned facts no longer match. A brand label in generated pixels, model fidelity and advertising claims must be reviewed against approved product assets.

The longer-term performance join is between workspace, exact published item, creative project revision, destination, metric definition and observation window. Missing data stays missing. Reviewers may associate an observed result with a shot as a hypothesis, then design an approved comparison. Approval of one version, unadjusted views, or the source reference's popularity supplies no evidence of causation.

## Operational limits

The new workflow performs bounded local analysis and synchronous rendering inside the request. The worker admits two concurrent media tasks per process. PostgreSQL admits up to three unresolved paid scene generations per workspace. Durable provider jobs are polled explicitly. Persistent render jobs, fleet-wide CPU admission, remote cancellation, resumable background polling, source-deletion propagation into every historical projection, private-storage integration on a real tenant, and a deployed worker with measured time and memory limits require qualification before customer release. Revocation blocks subsequent provider use. Content already saved into an editorial revision is retained under the current workspace lifecycle.
