## Privacy and product decisions left open

Private originals → neutral templates → private customer instances is a requirement, not a completed migration. Existing binding names and founder-specific contract fields demonstrate why mere renaming is inadequate. Before recommending proceed, resolve intended source ownership, local/cloud processing, collaborator access, preference undo/export/deletion, and template-update conflicts with participants and the product decision. A later implementation must separately test packaging exclusions and isolation between two customers. This source review cannot certify that future design.

Preserve Dashboard, Ideas, Scheduling, Channels, Analytics and Audience. The newer discovery plan moves onboarding and voice validation earlier than the old redesign roadmap. No framework rewrite, provider expansion or cloud provisioning is justified by the observations alone.

## What still needs evidence

The real task sequence and pain frequency; editing/time baselines; recognized voice; useful remembered preferences; mode and skill discoverability; tolerable setup; source privacy expectations; first-return occasion; and actual price/trial objections all need interviews. Live generation, two-platform draft quality, restart/conflict behavior, API permissions, account capability, scheduling, publication, analytics, replies and customer isolation were not validated in Phase 0. Do not infer them from buttons, stored candidates, schemas or prior reports.
