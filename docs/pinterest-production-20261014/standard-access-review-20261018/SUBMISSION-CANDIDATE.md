## Paste-ready purpose/use case

Rafii is a content workspace for creators and small businesses. Customers connect their own eligible Pinterest account through Pinterest's Authorization Code consent flow. Rafii identifies the connected account and reads authorized boards so customers can select an eligible destination for original image Pins prepared from content they supply.

A review shows the image, title, description, destination link, account, board and timing. A customer must approve each Pin. The implementation supports immediate creation and a Rafii-managed queue for individually approved Pins at a chosen local time. It stores the publishing intent and provider identifier to reconcile the result and checks the Pin through the API before displaying verified publication. Users can cancel pending work, pause future execution, reconnect or disconnect.

The proposed optional reporting feature reads available native impressions, saves, Pin clicks and outbound clicks for that customer's own authorized Pins. It distinguishes a successful result, an empty result and a failed read. It is not competitor research or platform benchmarking.

Rafii's Pinterest integration is in a restricted Trial validation phase. Real official OAuth, account binding and board discovery have passed for the authorized app-owner account. Live Pin creation, scheduled execution and own-Pin Analytics remain unaccepted and will be demonstrated before submission. Trial-created Pins are treated as visible only to their creator. Public customer connections remain disabled pending Standard approval, customer acceptance and a separately approved release.

Rafii does not request Pinterest passwords or session cookies. Current Pinterest API-to-agent/model gates remain closed. AI draft assistance uses customer-supplied content; it does not authorize use of Pinterest Materials to train or improve models. The final data-handling declaration will disclose and resolve essential identifier/receipt retention and organic metrics storage before submission.
