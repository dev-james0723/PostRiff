# Algorithm-aware creation

Apply this pass during every relevant draft, not only during analytics. Reviewed
2026-09-13; upstream algorithm references are pinned in `source-lock.json`.
Recommendation systems change. The evidence tiers below describe what is known;
they are not a guarantee that a post will travel.

## How to use

Choose a useful audience action from the brief: understanding, watching, saving
for use, sharing with a relevant person, substantive discussion or visiting a real
product/video. Shape the opening, format and payoff to serve it. Keep James's voice
and the actual claim intact. A natural discussion question is eligible; a demanded
"YES", forced controversy or fabricated vulnerability is not.

For each Studio variant, put one short distribution/retention rationale in `notes`.
Name the actual choice (for example, an early demonstration that fulfils the title),
not an alleged algorithm score. Where a tactic is experimental, label it a
hypothesis and suggest a meaningful metric only if available. Keep these notes out
of the caption. No experiment, schedule or reply is executed by this pass.

## Upstream heuristics worth testing

- LinkedIn: compare an observation-led and a result-led opening when both are true;
  try a concise post versus a fuller explanation for comparable topics.
- X/Threads: compare one self-contained thought with an earned multi-part explanation;
  test a specific question only when a conversation is the desired outcome.
- Instagram: test an early demonstration or reference-worthy card sequence; compare
  cover concepts with the same thesis and real assets.
- YouTube: test distinct honest title/thumbnail concepts with an unchanged payoff;
  inspect where the opening loses viewers before adding more cuts.
- TikTok: compare two clear spoken/visual openings, or a tighter explanation against
  a slower demonstration; preserve musical context and do not loop merely for views.
- Facebook: try a short observation versus a connected human story. The upstream
  under-80-character suggestion can seed a variant, never dictate every post.
- Timing, length, hashtags, link placement and native-media treatment can become
  experiments when the brief calls for them. Keep needed attribution and useful links.
  A first-comment variant requires an explicit derivative decision and later approval;
  it is not silently created or posted. Do not buy Premium or activate a provider.

Do not repeat the source's reach multipliers, signal weights, magic early-response
windows, detector scores or ideal length as verified facts. They may identify a
test question. They cannot promise results, invent urgency or impose a daily quota.
Publishing limits and media capabilities still come from current adapter checks.

## Learn without making up evidence

If suitable historical analytics exist, compare like-for-like platform, format,
language, audience, topic, time window and paid/organic distribution. Record one
changed variable, the hypothesis, source/evidence tier, metric denominator and
observation window. If analytics are absent, label the suggestion `untested` and
draft using audience fit. Never fabricate baseline performance or declare a winner
from one post. Save proposed experiments in existing draft notes; a future test's
publication and account actions use the normal approval workflow.
