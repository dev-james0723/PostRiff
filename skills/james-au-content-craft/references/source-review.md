# Source review and selection

This package is a James-specific editorial adaptation of MIT-licensed works by
Sergey Bulaev. Retain the bundled LICENSE. Reviewed source Markdown is archived
separately as reference material; no upstream skill is copied unchanged into the
active agent namespace. No lib, scripts, plugin manifests, hooks, environment files,
remote detector clients or external publishing defaults are installed.

23 selected writing skills plus all seven algorithm reference documents were
reviewed. Humanizer methods are consolidated once instead of installing seven
competing voice guides. Platform-specific writers and repurposers become the
seven playbooks; interview practice becomes optional, source-led intake.

## Adopted and adapted

- Source-led interview: reuse answers and ask about a real moment when needed;
  no compulsory story-bank creation, named-client disclosure or number requirement.
- Writers and repurposers: extract meaning; change delivery and native structure;
  retain sources and uncertainty rather than a master-caption translation.
- Humanizer: read aloud, remove actual filler and review proportionality; preserve
  James's intentional phrasing, questions, uncertainty and natural rhythm.
- Carousel/thumbnail/hook: a coherent promise/payoff, one visual job per element,
  actual media needs and separate spoken/on-screen/accessibility layers.
- Algorithm references: apply relevant discovery, retention and audience-response
  guidance. Official evidence and editorial inference are separated in algorithm
  practice; unverified numbers seed optional experiments, never guarantees.

## Excluded from this installation

Profile optimizers, employee advocacy, audience scraping, comment/reply automation,
engagement monitors, trend acquisition, bulk planning and provider setup are outside
this content-creation change. Planning, discovery and account adapters already
have project owners. We did not install Publora, Apify, Pixfaro or AI detectors.
No upstream instructions can override exact-content approvals or James's voice.

Algorithm tables contain vendor observations, inconsistent fold lengths and
provider-specific media limits. No source signal-weight table is treated as an
exact current platform contract. Algorithm advice remains usable with its evidence
tier; it is not categorically rejected.

The lock records SHA-256 of each downloaded source file. A future upstream change
requires a new editorial review and package version. Do not auto-update from HEAD.
