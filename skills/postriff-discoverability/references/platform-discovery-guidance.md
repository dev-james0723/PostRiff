# Platform discovery guidance

## Use and freshness boundary

These are routing principles, not permanent algorithm claims. Before final content is produced, consult the current channel adapter and authoritative platform documentation for supported fields, limits, structured data, account capabilities, and analytics. Record the source and retrieval time for volatile rules.

## Owned and search-led destinations

| Destination | Primary discovery work | Do not assume |
|---|---|---|
| Owned website/blog | Intent fit, clear answer, topic architecture, internal links, metadata, canonical/locale handling, accessible media, valid schema | A high plugin score causes ranking |
| LinkedIn article/newsletter | Useful professional/creative thesis, scannable sections, descriptive title, credible sources, relevant internal/external links | The same rules or fields as an owned website |
| YouTube long-form | Honest title promise, description context, chapters, transcript/entity clarity, thumbnail-message fit, viewer satisfaction | Tags or keyword repetition can compensate for weak retention |
| Google Business Profile/local page | Exact location/service relevance, accurate category/NAP/hours, real photos, current offers/events, review response policy | General social reach or permission to create fake reviews |
| Pinterest | Searchable title/description, board fit, evergreen vertical asset, valid approved destination | A generic campaign poster earns durable discovery |
| note / Naver Blog / Zhihu article | Native editorial structure, local language, entity clarity, sources, account/category context | Google keywords translate into Japanese, Korean, or Chinese search demand |

For structured data, recommend only vocabulary supported by the visible owned page. Social-platform metadata and hashtags are not Schema.org markup.

## Recommendation-led social platforms

| Destination family | Discovery emphasis | Typical failure to avoid |
|---|---|---|
| Instagram / Facebook / Threads | Clear first lines/frames, media-copy fit, audience relevance, saves/shares, alt text, profile/topic consistency | Stuffed hashtag blocks or one caption copied across Meta surfaces |
| TikTok / Reels / Shorts / Snapchat | First-seconds promise, spoken/on-screen clarity, pacing, completion, rewatch, native cover and sound rights | Treating a search keyword list as a video concept |
| X / Bluesky / Mastodon | One clear thought, timely context, useful threads only when sequence matters, accessible media and accurate links | Repeating keywords or forced controversy |
| Xiaohongshu / Weibo | Native Simplified-Chinese vocabulary, cover/title intent, useful detail, search-plus-recommendation fit, soft promotion | Literal translation, fake lifestyle evidence, or Google-centric keyword mapping |
| Douyin / Kuaishou / Moj / ShareChat | Regional language, immediate video value, culturally native framing, completion/share behavior, music rights | Assuming TikTok wording and route behavior transfer unchanged |
| Bilibili / WeChat Channels | Clear video premise, credible title/cover, appropriate depth, community and account context | Treating either as a duplicate YouTube upload |

## Community and opt-in destinations

- Reddit and Dcard: exact community/board rules, question fit, usefulness, disclosure, and discussion quality outrank campaign reach.
- Zhihu answers: bind the content to the exact current question; depth and evidence matter more than cross-post consistency.
- Discord, Telegram, Feishu/Lark, QQ, LINE, KakaoTalk, and WhatsApp Channels: optimize for subscriber relevance, clarity, notification cost, and exact destination; do not describe them as public-search SEO.
- Pixelfed and Mastodon: instance norms, accessibility, visibility, topical relevance, and conversation quality are instance-specific.

## Localization rule

Treat English, Hong Kong Traditional Chinese, Taiwan Traditional Chinese, Mainland Simplified Chinese, Japanese, Korean, and Indian regional languages as separate research markets. Preserve the same underlying claim and qualification, but allow different audience questions, vocabulary, examples, titles, and content formats. Machine-translated keyword lists never qualify a localized brief.

## Metrics by discovery model

| Model | Primary measures |
|---|---|
| Search-led | Query impressions, qualified clicks, index coverage, result CTR, useful conversion |
| Recommendation-led | Qualified reach, watch/completion time, saves, shares, profile visits, useful replies |
| Community-led | Rule compliance, discussion quality, accepted contribution, relevant replies/clicks |
| Opt-in broadcast | Opens/views where available, clicks, delivery/opt-out signals, subscriber value |
| Hybrid | Keep search and recommendation measures separate before interpreting the result |
