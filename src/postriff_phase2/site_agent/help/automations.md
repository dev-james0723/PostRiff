# Automations

An automation prepares drafts on a schedule: every week, every month, a countdown to a date, or once. Build one on [Automations](/app/automations) or ask Rafii in chat ("every Wednesday, find something about creativity and prepare it for LinkedIn").

## How its posts go out

Each automation has a publish policy:

- Drafts only: Rafii prepares drafts; you schedule them yourself.
- Review: each exact post waits for your approval before its publish time.
- Auto: posts publish at their time only after the owner allowed it for that exact automation, and only posts that pass every safety check. A post that fails a check waits for review instead.

An automation built in the four-step builder prepares drafts only; nothing is scheduled or published without your approval.

## Who controls it

Editors can create and edit automations. Only a workspace owner activates, pauses, resumes or cancels one. Changing anything except the name returns it to draft until the owner turns it on again.

## Each run

Each run drafts for the accounts, languages, content type and writer you saved. Apps, times or instructions written inside the brief are treated as text, not settings. Each run stays under its cost limit; a run whose quote is higher is held, never charged. A disconnected account is skipped with a note.

## Changing an automation

Open it on the Automations page, or ask Rafii ("move the Friday one to Thursday at 6 PM", "pause it for two weeks"). In the Rafii panel, a change is shown as a proposal with before and after; nothing changes until you press Apply, and a proposal made for an older version of the automation is refused.

## Run history

Every run keeps its history: when it drafted, which sources it used, who approved each post and what happened when it published. Ask Rafii "why wasn't Friday's post published?" to get the answer from that history.
