# Web research did not run

## Research is off for the workspace

An owner turns web research on or off on [Memory](/app/workspace/memory). When it is off, drafts use only what you added in [Ideas](/app/ideas).

## Research is switched off on this deployment

Some deployments turn research off entirely; drafts then use only your own sources.

## Nothing was worth using

An automation that researches skips a run when it finds nothing that clears its bar, unless it was set to draft without a source.
