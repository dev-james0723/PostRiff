# Memory (Brand Brain)

[Memory](/app/workspace/memory) shows what Rafii knows about your brand, as plain files: AGENT.md, IDENTITY.md, VOICE.md, BOUNDARIES.md and BRAND.md. They are rendered from your voice profile, brand context and the preferences an owner accepted, each time the page loads. The agent cannot change the files itself.

## Which files a writer receives

The files marked "Given to writing routes" are what a writing route receives before it drafts. Routes on your own machine always receive them; the cloud model reads them only if an owner allows it, and never a boundary marked private or local-only.

## Proposals, never silent changes

When you tell Rafii how to write ("never use emojis"), or your edits show a pattern, it proposes a preference. An owner remembers, rewords or dismisses it; a suggestion nobody decides expires. Accepted preferences appear in VOICE.md under "Learned from how you edit" and shape future drafts only. An owner can pause or retire a learned preference later.

## Asking Rafii what it remembers

Ask "what do you remember about my brand?" in the Rafii panel. It lists the files and their purpose from this page; it does not send private memory to a cloud model unless an owner allowed cloud memory.
