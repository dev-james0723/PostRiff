# Analytics

[Analytics](/app/analytics) shows post performance from providers that report it.

## Each provider keeps its own definitions

A "view" on Threads is not a "view" on Instagram. Metrics are shown with their native names and never added across platforms.

## Unavailable is not zero

When a provider has not reported a metric, Rafii shows "Unavailable". A real zero is shown as 0.

## When Rafii reads

A reading happens when Rafii's worker asks the provider for a post's insights after the provider verifies the publication. Each row carries the time of its own reading.

## Why some accounts have no numbers

Analytics is a separate permission from publishing, granted per account. Some providers do not offer insights to this app at all (LinkedIn's official API is one), and those accounts stay Unsupported.
