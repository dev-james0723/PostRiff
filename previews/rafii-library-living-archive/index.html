What I chose

Five interaction ideas survived the filter. Each one has a job. None is allowed to become permanent decoration.

01 · Selected

Spatial archive folders

Borrow the “contents fan open” idea from Rare UI, but rebuild it in Rafii’s monochrome material language. It gives Collections one memorable physical interaction without infecting every card with 3D effects.

02 · Selected

Card → detail morph

Inspired by Motion Primitives’ morphing popover. A file should feel like the same object expanding into a detail canvas, not like an unrelated right sidebar appearing.

03 · Selected

Sliding filter surface

Use the Animated Background principle for file-type filters. It makes the toolbar feel continuous while keeping every option readable and keyboard-accessible.

04 · Selected

Selection action island

Borrow the compactness of a Floating Dock, but only after files are selected. Powerful multi-file actions without a permanent toolbar.

05 · Selected

Drag-only ambient grid

Use the reactive upload-space idea only while dragging files or when the Library is empty. The normal archive remains visually quiet.

Upload becomes a moment

The Upload button stays. Dragging simply gives the whole workspace a receiving state, which is both more useful and more expressive.

What I did not choose

More animation is not automatically more artistic. These ideas make the product less useful if applied broadly.

Focus Cards blur

Rejected for the main grid. Blurring sibling files hurts scanning and does not translate well to keyboard or touch.

Full parallax cards

Rejected. 3D mouse parallax across hundreds of files would become tiring, expensive and visually noisy.

Permanent reactive background

Rejected. The grid effect is stronger when it appears only in an upload/empty state.

Heavy glass everywhere

Rejected. Glass stays on transient controls and overlays; file previews need calm contrast.

Knowledge graph as homepage

Demoted to a Connections view after real relationship data exists. Otherwise it is visual theatre.

New animation libraries

Rejected for Phase 1. Rafii already has Motion, dropzone and enough primitives.

Build order

The design should become more useful before it becomes more intelligent.

Phase 0

Protect the candidate

Snapshot the current Universal Library WIP. Do not reset migration 047 or overwrite the dedicated worktree.

Phase 1

Living Archive shell

Filters, better cards, detail morph, multi-select, action island, drag state, sparse/empty composition, accessibility.

Phase 2

Collections + previews

Only with real data: manual collections, PDF/PPT rendering, usage details, generated-document ingestion.

Phase 3

Library intelligence

Approved analyzer, semantic retrieval, Ask Rafii with citations, smart collections and optional Connections view.
